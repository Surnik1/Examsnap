# ⚡ ExamSnap — AI-Powered Quiz Generator Web App

**ExamSnap** — современное веб-приложение для старшеклассников (10–11 классы), абитуриентов и студентов, которое моментально превращает скучные лекции, конспекты и параграфы учебников в интерактивные проверочные тесты из 5 вопросов с подробным разбором каждого ответа.

---

## 🚀 Возможности
- **Мгновенная генерация тестов:** Вставьте текст конспекта (или нажмите на любой готовый пресет) и получите готовый тест за 5 секунд.
- **Интерактивный плеер:**
  - Прогресс-бар и подсчет баллов в реальном времени.
  - 4 варианта ответов (A, B, C, D) для каждого вопроса.
  - Мгновенная обратная связь: верный ответ подсвечивается зеленым, неверный — красным.
  - Блок с подробным методическим объяснением сразу после ответа.
- **Экран результатов:**
  - Итоговый балл (например: *🎉 4/5! Отличный результат перед контрольной!*).
  - Процент точности и мотивирующие рекомендации.
  - Возможность повторного прохождения теста.
  - Полный сводный разбор всех 5 вопросов с показом сделанных ошибок и правильных вариантов.
- **История тестов:** Быстрый сайдбар с возможностью переключения и прохождения любого сохраненного теста из базы данных.
- **🛡️ Режим Zero-Fail (Абсолютная надежность для демо):**
  - Если ключ Gemini API отсутствует, закончилась квота или пропал интернет, бэкенд автоматически переключается на встроенный интеллектуальный генератор на базе ключевых слов и контекстного анализа текста.
  - Приложение гарантированно не упадет во время живой демонстрации!

---

## 🛠️ Стек технологий
- **Backend:** Python 3.11+, Django 5.x.
- **Database:** SQLite (без необходимости дополнительной настройки).
- **Frontend:** Django Templates + Tailwind CSS (via CDN) + Vanilla JavaScript (Fetch API).
- **AI Engine:** Google Gemini API (`google-genai` SDK) с генерацией структурированного JSON.

## 📦 Быстрый старт

### 1. Установка зависимостей
```bash
pip install django python-dotenv google-genai
```

### 2. Настройка окружения (опционально)
Файл `.env` уже создан в корне проекта. Если у вас есть ключ Google Gemini API, укажите его:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```
> *Примечание:* Если ключ не указан, ExamSnap продолжит работать в режиме Zero-Fail Fallback Mode с готовыми высококачественными пресетами и контекстными тестами.

### 3. Запуск миграций базы данных
```bash
python manage.py migrate
```

### 4. Запуск сервера разработки
```bash
python manage.py runserver
```
Откройте браузер по адресу: **[http://127.0.0.1:8000/](http://127.0.0.1:8000/)**

## ⚡ Пресеты для быстрого демо (90 секунд)
На главном экране доступны три быстрых пресета в один клик:
1. **🌿 Биология:** Фотосинтез, световая и темновая фазы, цикл Кальвина, фотолиз воды.
2. **💻 Информатика:** Алгоритмы, сложность Big O, неизменяемые структуры Python, генераторы yield.
3. **🏛️ История:** Великая Отечественная война, Сталинградская и Курская битвы, операция «Багратион».

## 🧪 Запуск тестов
Для запуска автоматических тестов:
```bash
python manage.py test
```
Все 7 тестов проверяют валидацию, генерацию по пресетам, контекстный fallback, историю тестов и модели базы данных.
